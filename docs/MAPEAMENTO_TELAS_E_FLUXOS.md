# Telas e fluxos — quatro fases

Versão atual após implementação, em 26/10/2026. A relação completa de telas, ações, dados, permissões, dependências e critérios está dividida nesta ordem:

1. [Morador](MAPEAMENTO_FASE_1_MORADOR.md): entrada/cadastro → condomínio → triagem → treino → execução/feedback → aulas/eventos → reservas/serviços → suporte/perfil.
2. [Coach](MAPEAMENTO_FASE_2_COACH.md): convite/vínculo → agenda → alunos → anamnese/segurança → criação/revisão → presença → evolução/feedback.
3. [Síndico](MAPEAMENTO_FASE_3_SINDICO.md): acesso → ativação → indicadores → aulas/profissionais → comunicados → Health Day → áreas/solicitações.
4. [Admin](MAPEAMENTO_FASE_4_ADMIN.md): condomínio → operação → contas/convites/permissões → profissionais → solicitações → auditorias → acompanhamento.
